# Third-party notices

LinuxFlow's own code is under the MIT licence (see `LICENSE`).
LinuxFlow is a native Linux application written in Rust; it is distributed as a `tar.gz`
archive. It uses the components below, each under its own licence.

## Components outside Cargo

| Component | Role | Licence |
|---|---|---|
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) and ggml (compiled into the binary through the `whisper-rs` crate) | speech recognition engine | MIT |
| OpenAI Whisper model weights, in GGML format, **downloaded at the user's request** (not shipped in the archive) | speech recognition model | MIT |
| Silero VAD (GGML model, downloaded with the Whisper model if the user accepts it) | voice activity detection | MIT |
| GTK 4 and libadwaita (system libraries, **dynamically linked**, not shipped) | user interface | LGPL-2.1-or-later |
| Vulkan loader, ALSA, xkbcommon (system libraries, dynamically linked, not shipped) | GPU access, audio capture, keyboard layouts | Apache-2.0, LGPL-2.1-or-later, MIT |
| Figtree font (shipped in `share/fonts/linuxflow` with `OFL.txt`; the application falls back to the system font if it is removed) | interface font | SIL Open Font License 1.1 |

GTK 4 and libadwaita are LGPL libraries linked dynamically: you can replace them by your own
build of the same libraries (see `BUILD.md` to rebuild LinuxFlow). No NVIDIA/CUDA file is
shipped or required: GPU acceleration uses the Vulkan loader of your system.
